Passaggi:
1) PUT  ->  Settaggio valori soglia per specifico dispositivo
2) POST ->  Invio misure dei dati
3) GET  ->  Lettura valori raccolte dallo specifico device
4) GET  ->  Controllo di eventuali Alerts per valori fuori range
5) POST ->  Richiesta immediata di acquisizione parametri
6) GET  ->  Controllo della presenza del comando inviato (stato=PENDING)
7) GET  ->  Polling: Controllo di presenza del comando nei /pending
8) POST ->  Esecuzione del comando (EXECUTED) --> risposta con ACK
9) GET  ->  Controllo della corretta esecuzione del comando (stato=EXECUTED)
